# China Methane Infrastructure Mapping

## Overview

This code was used to identify oil and gas facilities, and tanks within those facilities for target regions in China. Under the umbrella of MethaneSAT projects at the Environmental Defense Fund, this project is the China Methane Infrastructure Mapping. This pipeline can be reused and adapted to tackle similar goals in other regions.

> *The code and data is divided up into the following sections*

-   Step 1: OSM query for arbitrary location (MSAT Scenes)

-   Step 2: Imagery Acquisition for given geographic dataframes

-   Step 3: Model Training

-   Step 4: Processing results of Model prediction

-   Data Folder: Data created by and used in the running of the pipeline

-   China Methane Infrastructure Mapping - Capstone: Paper detailing process and results

-   requirements.txt: Extensive list of packages used in analysis
